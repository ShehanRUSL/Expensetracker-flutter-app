# 💸 Expense Tracker – Flutter App

**Expense Tracker** is a simple Flutter mobile app to help you track daily expenses easily.  
It uses **SharedPreferences** for offline storage, so all your data stays on your device.

---

## ✨ Features

* 💰 **Add Expenses**
  * Add title, amount, and date
  * Validates input before adding
* 🗑️ **Delete Expenses**
  * Remove individual expenses easily
* 📊 **Expense List**
  * Shows all your expenses in a scrollable list
  * Date and amount are displayed clearly
* 💾 **Offline Storage**
  * Data saved locally using `SharedPreferences`
  * Works without internet
* 🎨 **Clean UI**
  * Gradient background
  * Modern Material Design
  * Floating Action Button for adding expenses

---

## 🚀 How to Run This Project on Your PC

### Prerequisites

* Flutter SDK installed
* Android Studio / VS Code
* Android Emulator or Physical Device

### Steps

```bash
git clone https://github.com/ShehanRUSL/Expensetracker-flutter-app.git
cd Expensetracker-flutter-app
flutter pub get
flutter run
```
